Manipulação do DOM

O DOM (Document Object Model, ou Modelo de Objeto de Documento) é uma representação em formato de árvore que o navegador web cria a partir do seu código HTML.

O que ele faz

  • Transforma cada tag, texto e atributo do HTML em um objeto (ou "nó") interativo.
  • Permite que linguagens de programação, como o JavaScript, leiam e modifiquem a página em tempo real sem precisar recarregá-la.

Exemplos Tags HTML

  • div
  • p
  • h1
